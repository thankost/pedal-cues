Quick answers

Nothing happens on the pedal

Check the cue track's MIDI hardware output in your DAW and that the pedal's MIDI device is enabled there. Press a tile's play button to test. In the standalone app, pick a port in MIDI Setup > Test your pedals.

Sync from QC says "No Quad Cortex found"

Connect the QC's USB port (a MIDI cable isn't enough), switch it on, and quit Cortex Control, which keeps the USB connection to itself. On Linux, install the USB permission rule from the guide once.

The Whammy doesn't react

If the QC is on USB and the Whammy hangs off the QC's Thru, that can't work: the QC doesn't forward USB MIDI. Open the Wiring guide in the app for setups that work.

macOS says PedalCues "is damaged"

It isn't. macOS blocks apps Apple hasn't notarised. Run the xattr -cr command from the install steps, or use Privacy & Security > Open Anyway.

How do I update?

When the app shows Update to vX.Y.Z, click it and download. Close your DAW and replace the plugin files the same way you installed them. Your setup and projects are kept. See What's new for what changed.
